**Tag** — pill-shaped category filter and topic label.

Use in carousel footers, service listings, and post topic rows to help users scan content categories.

```jsx
<Tag variant="filled-gold" active>VIP Трансфер</Tag>
<Tag variant="outlined-gold">Fast-Track</Tag>
<Tag variant="filled-coral">Острова</Tag>
<Tag variant="filled-sea" onClick={handle}>Пляжи</Tag>
<Tag variant="outlined-white">Виза</Tag>
<Tag variant="filled-lime">Инсайдер</Tag>
```

Variants: outlined · outlined-gold · outlined-white · filled · filled-gold · filled-coral · filled-sea · filled-lime
Supports active state (forces gold highlight) and optional leading icon.
